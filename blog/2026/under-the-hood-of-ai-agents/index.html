What's really
happening under the hood of an AI agent

It feels like magic. It isn't. It's a very well-read brain, wired into a workshop.

Written for someone who has never touched code — so that the next time an "AI agent" does something impressive, you can picture exactly how it pulled it off.

Start here

Two parts, always

Every AI agent — the coding assistant, the research assistant, the little bot that books your meetings — is built from just two things stacked together.

There's the model, which is the brain: it thinks, reads, and writes. And there's the harness, which is the workshop built around that brain: it gives the brain memory, tools, instructions, and a way to actually do things in the world.

Keep these two straight and the rest of this page falls into place. Almost everything that looks magical is really just the harness handing the brain the right thing at the right moment.

The model

A brilliant person in a sealed room

Picture the smartest, most well-read person you know. Now lock them in a room with no phone, no internet, and no way to remember today once it's over. Slide a question under the door on a piece of paper, and they slide back a beautifully written answer. That is a model.

It has read a staggering amount — books, articles, conversations, code — but all of that reading stopped at some point in the past. So the model is extraordinary at thinking, explaining, and writing, and helpless at anything that needs fresh information or action.

Can do

Reason with what it knows

Explain a tax rule, draft an email, spot a bug in code, summarise a messy paragraph, translate a menu.

Can't do — alone

Reach the live world

Tell you today's weather, open your files, send a message, or remember what you said yesterday.

This is the crucial idea: the model by itself can only talk. Everything else — looking things up, remembering, taking action — is the harness's job. Which is exactly where we go next.

One more thing people mix up: the model's capabilities are just how good the brain is — how well it reasons, how carefully it follows instructions, how much it can hold in its head at once. A stronger model is a smarter person in the room. It still can't see outside the room. That's a harness problem, not a brain problem.

The harness

The workshop around the brain

The harness is the room set up around that sealed-off genius. On its own the brain can only answer notes. The harness is what turns it into a worker who gets things done. It does four jobs.

1 · It keeps memory

The brain forgets everything between notes. The harness keeps a running transcript so the conversation actually builds on itself.

2 · It hands over tools

A phone to the weather service, a calculator, a way to read a file. The brain asks; the harness fetches.

3 · It pins up the instructions

A standing note above the desk saying who this worker is and how to behave. (That's the system prompt — coming up.)

4 · It runs the loop

Think, act, look at the result, think again — over and over, until the job is done. This loop is the whole trick.

A model is a brain. An agent is a brain the harness has given hands, memory, and a to-do list.

The loop

How thinking becomes doing

Here's the rhythm every agent runs on. It's not a single flash of genius — it's a patient loop, repeated as many times as the task needs.

Tools

What a "tool" actually is

A tool is just a specific action the harness knows how to perform on the brain's behalf. The weather lookup was one. But the same idea covers everything an agent can do rather than just say:

Search the web
Fetch a live page or search result.
Read a file
Open a document on your computer.
Run a calculation
Do maths reliably, not by "feel".
Send a message
Post to Slack, email a colleague.
Edit code
Change a line in a real file and save it.
Check a calendar
See when you're free, book a slot.

The brain never touches any of these directly. It writes a little request — "read the file report.txt" — and the harness carries it out and reports back. Give an agent more tools and it can do more; take them away and even a genius model can only chat. An agent's real-world power is mostly a question of which tools it's been handed.

The system prompt

The job description pinned above the desk

Here's a puzzle. A sales agent and a marketing agent might run on the exact same brain — the same model. So why do they behave so differently?

Because of the note pinned above each one's desk. That standing instruction is called the system prompt: it tells the brain who it is, what it's here to do, what tone to use, and what to avoid — before a single question arrives. Same brilliant employee; two completely different job descriptions.

System prompt · Sales

"You are a sales assistant."

Qualify the lead, understand their budget, move toward booking a demo. Be warm, persuasive, and concrete about pricing. Never over-promise.

System prompt · Marketing

"You are a marketing strategist."

Find the audience, sharpen the message, draft campaign copy. Think in themes and channels. Favour clarity and brand voice over closing a single deal.

Swap those two notes and the sales agent starts writing campaigns while the marketing agent starts chasing deals — with no change to the underlying model at all. The system prompt is how one brain becomes a hundred different specialists. It's also where a company bakes in its rules: "always cite your source", "never share internal pricing", "reply in Hindi if the customer writes in Hindi".

Skills

Recipe cards in the drawer

A system prompt sets the overall job. But some tasks have a right way of being done that's too detailed to keep pinned on the wall all the time. That's what a skill is: a written playbook the worker pulls out of a drawer only when a matching task comes up.

Think of a folder of recipe cards. Each card has a title, a note about when to use it, and step-by-step instructions. The worker glances at the titles, and when a task matches — "ah, the customer wants a PowerPoint" — it pulls that one card and follows it.

A drawer of skills

Make a slide deck
When someone asks for a presentation → build clean slides, one idea each.
Write in our brand voice
When drafting anything public → use the tone guide, avoid these words.
Do expense reports
When handed receipts → sort, total, flag anything over the limit.

So how do people write a skill?

This is the reassuring part: a skill is mostly just clear instructions written in plain English — not code. You write down, as if training a new hire, three things: a short name, a line about when to use it, and the steps to follow. You can also tuck in an example or a checklist. The harness keeps this in the drawer and slips it to the brain at the right moment.

That's why skills are so powerful for ordinary teams: your best salesperson can capture how they actually do it in a page of instructions, and every agent can now follow that recipe perfectly, every time. Tools give an agent new hands; skills give it new know-how.

Toy example #2 · scaling up

Now the hard task: "Research this market for me"

A quick weather lookup is one trip around the loop. But suppose you ask for something big — "Put together market research on electric scooters in India: the main players, their pricing, what customers complain about, and where the gaps are."

One worker could grind through this alone, tool call after tool call. But it's slow, and it's a lot to hold in one head. So a capable harness does what a good manager does: it breaks the job into pieces and hands each piece to its own copy of the worker, all at once.

One manager, several agents working in parallel

Lead agent — splits the job & combines the findings
Agent A
List the main brands & models
Agent B
Gather pricing across sellers
Agent C
Read reviews for complaints
Agent D

Each sub-agent runs its own think–act–observe loop, using search and file tools, following any relevant skills. When they finish, they hand their findings back to the lead agent, which reads all four, resolves overlaps, and writes the single report you asked for.

That's the whole shape of "complex AI work". Not one impossibly-clever step — but a lot of simple loops, run in parallel, then stitched together. The same pattern builds a piece of software, plans an event, or reconciles a spreadsheet.

The concrete example

Where you've seen all of this: a coding agent

A coding assistant like Claude Code is exactly the machine we've described, aimed at one profession. The brain is the same kind of model. Its tools are things a programmer needs: read a file, edit a file, run the program, search the project. Its system prompt says "you are a careful software engineer." Its skills are playbooks like "how to write a good commit" or "how we structure tests here." And it runs the same loop — read the code, make a change, run it, see the error, fix it, repeat — until the feature works.

Now here's the leap: nothing about that shape is specific to coding. Swap the tools and the instructions and you have a coworker for a different job entirely.

Coding agent

Tools: edit files, run code, search a codebase.
Prompt: "careful engineer."
Skills: testing, commit style.

Office coworker agent

Tools: read documents, send email, build a deck, check the calendar.
Prompt: "helpful operations assistant."
Skills: your report format, your brand voice.

Same brain. Same harness idea. Same loop. Just a different kit on the desk. That's why one underlying technology can show up as a coding helper, a research analyst, a sales rep, and a marketing strategist — the differences you notice are almost entirely tools, system prompt, and skills, not four different kinds of intelligence.

The whole thing, in one breath

So, no magic

  1. A model is a brilliant, well-read brain that can only think, read, and write — sealed off from today's world.
  2. A harness is the workshop around it: memory, tools, instructions, and a loop.
  3. Tools are the specific actions the harness performs for the brain — a weather lookup, a file edit, a message. They're how an agent does instead of just talks.
  4. The system prompt is the job description that turns one brain into a sales rep, a marketer, or an engineer.
  5. Skills are plain-English recipe cards the worker pulls out when a matching task appears — new know-how, no code required.
  6. Hard jobs are just many small loops run in parallel by several sub-agents and stitched together by a lead.

Next time an agent does something that makes you go "how did it know that?" — you can answer your own question. It didn't know. It figured out what it needed, reached for the right tool, read the result, and told you. Patiently, in a loop. That's the machine.
